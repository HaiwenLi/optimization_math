# 算法调研扩展总路线图

- **日期**：2026-11-17
- **状态**：顶层规划（索引），逐类落实中
- **定位**：在已落地的非负 LASSO/弹性网（FISTA + 三分裂 ADMM）之上，把算法调研与自建案例验证扩展到五类经典优化问题；**聚焦算法本身**，不接入实际成像功能（FFT 算子 / 体素基准 / EF-Spin 联调属后续验证，不在本工程内）。

## 1. 目标与原则

- **目标**：为每类问题完成「调研文档 + 求解器 + 证书 + 自建基准」四件套，用经典/特殊优化问题作为测试案例，检验各算法的实际效果（收敛速度、精度、sparsity、鲁棒性）。
- **原则**：
  1. **调研先行、验证随后**：先写清单式调研文档（问题形式 → 算法谱 → 证书推导 → 推荐），再落代码与基准。
  2. **增量、不破坏**：现有 `certificates.py`（非负 LASSO/弹性网）与 `solvers/fista.py`、`solvers/admm.py` 保持不动；新问题通过**独立证书模块**与**独立求解器模块**落地，避免回归。
  3. **证书可比**：每类问题都推导并实现对应的 KKT 最优性条件与相对对偶间隙，延续现有「证书与算法无关、横向可对比」的口径。
  4. **NumPy only**：延续运行时只依赖 NumPy 的约束；求解器内层不引入 SciPy 求解器。
  5. **案例自建**：不依赖外部 ground-truth 求解器；用小/中规模、可解析或可独立验算的案例做验收锚点。

## 2. 覆盖范围与优先级

| # | 问题类型 | 核心形式 | 新证书要点 | 优先级 |
|---|---|---|---|---|
| T1 | 带符号 LASSO / 弹性网 | `min ½‖Ax−y‖² + λ‖x‖₁ (+ μ/2‖x‖²)`，无非负约束 | soft-threshold KKT（`\|Aᵀr\|∞` 阈），去掉 `x≥0` 分支 | P0 |
| T2 | 稀疏 logistic 回归（penalized logistic） | `min Σᵢ log(1+e^{−yᵢ·wᵀxᵢ}) + λ‖w‖₁` | 光滑损失下的 KKT + Fenchel 对偶下界 | P0 |
| T3 | Fused LASSO / TV 去噪 / 去卷积 | `min ½‖Ax−y‖² + λ‖x‖₁ + τ‖Dx‖₁`（D=差分/图） | 引入中间变量的分裂 KKT + 对偶 | P0 |
| T4 | 凸约束 / 二次规划（QP） | `min ½xᵀQx + cᵀx s.t. l ≤ x ≤ u, Cx ≤ d`（含 NNLS、box、单纯形） | 拉格朗日 KKT + 强对偶 gap | P1 |
| T5 | 结构化稀疏：group LASSO / 低秩 | `λΣₖ‖x₍ₖ₎‖₂`；核范数 `λ‖X‖*` | group-KKT / 谱 KKT + 对偶 | P1 |

> T1–T3 为 P0，T4–T5 为 P1。优先级依据：与现有非负 LASSO 代码的复用距离（T1 最近，几乎只是去掉 box）、以及算法主战场的代表性与自建案例的可验算性。

## 3. 每类的交付物模板

每一类（T1–T5）都产出以下四件套，缺一不可：

1. **调研文档** `docs/survey/<日期>-<slug>-调研.md`
   - 问题形式与记号、应用背景
   - 算法谱（近端 / 分裂 ADMM / 坐标下降 / 内点……）与各算法优缺点、收敛判据
   - 证书推导（KKT + 对偶下界，逐式）
   - 选型建议与与本仓库现有代码的复用关系
   - 参考文献（可核验）
2. **证书模块** `src/optimization_math/certificates_<slug>.py`
   - 复用 `Certificate` dataclass 或定义等价结构
   - `compute_certificate_<slug>(...) -> Certificate`
3. **求解器模块** `src/optimization_math/solvers/<slug>.py`
   - 至少一个主推求解器（近端 / ADMM / 坐标下降择其最适配者）
   - 与证书模块解耦，收敛以证书为准
4. **测试与基准** `tests/test_<slug>.py` + `benchmarks/`（或并入测试）
   - 解析锚点（闭式解 / 可手算小例）
   - 自建案例（如 penalized logistic 的合成二分类、TV 去噪的阶梯信号、group LASSO 的分组稀疏信号、QP 的 box/单纯形投影）
   - 收敛/精度/sparsity 指标断言

## 4. 自建案例清单（草案）

| 案例 | 归属 | 说明 |
|---|---|---|
| 阶梯/分段常数信号 + 高斯噪声 | T3 TV 去噪 | 闭式可验（1D fused lasso），测 TV 项恢复 |
| 高斯设计矩阵下的稀疏回归 | T1 | 控制 λ，验证 soft-threshold 解的性质 |
| 合成二分类（对数几率模型 + 稀疏权重） | T2 | 验证 penalized logistic 恢复真实支持 |
| 非负最小二乘 / box 约束 QP | T4 | 与已有非负 LASSO 交叉对照 |
| 分组稀疏信号（组内共激活） | T5 group | 验证 group LASSO 的分组选择效应 |
| 秩受限矩阵补全（低秩） | T5 低秩 | 验证核范数松弛的秩恢复 |

## 5. 执行顺序

1. **T1 带符号 LASSO/弹性网**（P0，最接近现有代码，先打通「证书模块化 + 求解器 + 基准」的复用范式）
2. **T2 稀疏 logistic**（P0，光滑损失 + 新证书族的代表）
3. **T3 Fused LASSO / TV / 去卷积**（P0，分裂算法主战场，D 算子需要新的差分算子接口）
4. **T4 QP / 盒约束**（P1，活动集/投影范式）
5. **T5 结构化稀疏 group/低秩**（P1，group 范数与核范数的 proximal 与谱证书）

每类独立成文、独立提交；全部完成后统一更新 `README.md` 路线图与 `docs/survey` 索引。

## 6. 明确不做（本轮）

- 不接入实际成像功能：FFT 算子、285,696 体素基准、EF-Spin 联调。
- 不引入 SciPy 求解器作为运行依赖（可作为小算例的外部对照参考，但不纳入 `compute_certificate` / 主求解器的运行时路径）。
- 不改动已合并的 `certificates.py` / `fista.py` / `admm.py` 的公开行为。
