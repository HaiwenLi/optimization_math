# L1 / L2 / L1+L2 正则化反问题求解算法调研

- **日期**：2026-11-13
- **适用背景**：轴向增益编码三维荧光重建（y = A o + b + n，o ≥ 0 且稀疏）
- **状态**：初稿（算法选型调研，供求解器升级与对照验证决策参考）

---

## 1. 调研范围说明

**应用背景**。轴向增益编码三维荧光重建的测量模型为 y = A o + b + n，要求重建体素 o ≥ 0 且稀疏；A 是"多层二维卷积 + 轴向编码加权求和"算子——没有显式矩阵，只能以逐层 2D 卷积（FFT 加速）方式应用 A 与 Aᵀ；完整体素 96×96×31 = 285,696 ≈ 2.86×10⁵。当前实现为两阶段流程：① 工作列自动生成（贪心匹配追踪类，按残差相关选列）；② 支撑内非负最小二乘（NNLS）幅度校正；收敛以投影 KKT 条件与相对对偶间隙判定。

**覆盖的算法族**（11 类，另加弹性网与深度展开的简评）：

1. 增广拉格朗日（ALM）与 Bregman 迭代（含 split Bregman）
2. 变量分裂方法
3. 交替方向乘子法（ADMM）
4. 近端梯度类：ISTA、FISTA 及非负投影变体
5. 坐标下降（glmnet 类）
6. LARS / 同伦法
7. 内点法（l1_ls 类）
8. 贪心类：OMP、CoSaMP、工作列/匹配追踪策略
9. 一阶自适应方法（Adam + 重参数化）
10. L2 正则化（岭回归 / 截断 SVD）与 L1+L2 弹性网
11. 深度展开（deep unfolding，简述）

**统一评估维度**：非负约束支持方式（原生 / 投影 / 重参数化 / 罚函数）、FFT 与并行友好度、内存占用、28.6 万体素规模可行性、实现复杂度、与当前工作列实现的关系；每个算法族另给出收敛判据（KKT / 对偶间隙 / 残差类）。

**不在范围**：TV 等图像正则子的专门讨论、分布式/异步优化实现细节、除深度展开外的学习类方法、λ/μ 超参数选择理论。

## 2. 问题设定与统一收敛证书

### 2.1 问题族与记号

全文记 r = A o + b − y 为拟合残差，g = Aᵀ r 为相关图（也是数据项梯度）。

| 问题 | 形式 | 说明 |
|---|---|---|
| 非负 LASSO [1] | min_{o≥0} ½‖Ao + b − y‖² + λ‖o‖₁ | 主问题；λ 由噪声水平与稀疏度期望确定 |
| 非负弹性网 [2] | min_{o≥0} ½‖Ao + b − y‖² + λ‖o‖₁ + (μ/2)‖o‖² | μ > 0 改善条件数、抑制轴向跨层相关 |
| NNLS [3] | min_{o≥0} ‖Ao + b − y‖² | 当前支撑内幅度校正的子问题 |
| 岭回归 [4] | min_o ½‖Ao + b − y‖² + (μ/2)‖o‖² | 无稀疏性、无约束，作对照与初值 |

对本项目关键的算子结构性质：

- **算子只能隐式应用**：A o = Σ_z c_z (K_z ⊛_2D o_z)，Aᵀ r 同理。一次 A/Aᵀ 对 ≈ 数十个 96×96 的 2D FFT（核可预分解），毫秒量级；解向量一个 float64 数组仅约 2.3 MB。**28.6 万体素对一阶方法而言是"小问题"**——瓶颈在条件数而非规模。
- **轴向编码使 AᵀA 跨层耦合**：相邻 z 层的系统列高度相关（高相干），这是贪心法选错列的主要风险来源，也是弹性网 L2 项的直接用武之地。
- **弹性网恒等式**：½‖Ao + b − y‖² + (μ/2)‖o‖² = ½‖[A; √μ I] o − [y−b; 0]‖²，故任何 LASSO 求解器都可直接解弹性网，无需改算法。
- **背景项 b**：已知则从 y 中扣除；未知则作为附加自由块联合估计（ADMM / 工作列都容易，FISTA 需增广变量与箱约束）。

### 2.2 投影 KKT 条件（非负 LASSO 的最优性证书）

o* 为最优解 ⟺ o* ≥ 0 且（记 g* = Aᵀ(Ao* + b − y)）：

- o*_i > 0 ⇒ g*_i = −λ（支撑上相关恒等于 −λ）
- o*_i = 0 ⇒ g*_i ≥ −λ（支撑外相关不超过 −λ）

归一化违反度指标：ε_KKT = max( max_{o_i>0} |g_i + λ| , max_{o_i=0} (−λ − g_i)⁺ ) / max(λ, ‖g‖∞)。

**要点**：ε_KKT ≤ tol 即为全局最优证书，**与用哪种算法得到 o 无关**——因此下文所有算法都能与当前工作列实现按完全相同的口径验收。

### 2.3 对偶问题与相对对偶间隙

对 r = A o + b − y 引入等式约束与乘子 ν，得对偶问题：

> max_ν −½‖ν‖² + (b−y)ᵀν　s.t.　Aᵀν ≥ −λ·1

- 取 ν = r（残差）时，对偶可行性条件恰为 §2.2 的 KKT：收敛良好的迭代末端残差自动（近似）可行，直接代入即得对偶值 d。
- 中途迭代可取保守下界 ν = 0（d = 0），或按 SPGL1 [5] 的做法取 ν = θ·r 并解最大可行 θ。
- 相对间隙 gap = (p − d)/max(1, |p|, |d|)，其中 p = ½‖r‖² + λ‖o‖₁。

**弹性网（μ > 0）的增广对偶**：由 §2.1 增广恒等式（增广算子 [A; √μ I]）推导，取 ν = θ·r、η = θ·√μ·o（r = Ao + b − y），令 q = Aᵀr + μo，对偶可行性为 θ·q ≥ −λ·1。取 θ = min(1, min_{q_i<0} λ/(−q_i))（q 无负分量时 θ = 1）即构造出可行对偶点，对偶值 d = −(θ²/2)(‖r‖² + μ‖o‖²) + θ(b−y)ᵀr；μ = 0 时退化为上面的 LASSO 对偶。

**结论**：任何产出 (o, r = Ao + b − y) 的算法（贪心、FISTA、ADMM、Bregman……）都能用同一对 (ε_KKT, gap) 证书横向对比。这是本调研反复强调"证书可比性"的原因，也与当前实现的收敛判定完全一致。

## 4. 增广拉格朗日（ALM）与 Bregman 迭代（含 split Bregman）

- **核心思想**：对带约束的 min f(o) + λ‖o‖₁（约束为 ‖Ao+b−y‖ ≤ ε 或 o ≥ 0）构造增广拉格朗日：在拉格朗日函数上加二次罚项，交替做原始变量最小化与对偶乘子上升。Bregman 迭代把二次罚换成 Bregman 距离，得到极简的"残差加回"三行格式 [6][7]；split Bregman 先把 L1 项分裂到辅助变量再做 Bregman 迭代 [8]。
- **适用场景与规模**：中大规模、算子只能隐式应用（FFT 卷积）的图像复原/压缩感知主力方法；28.6 万体素完全可行。
- **优点**：约束式 BPDN 形式 [9] 回避调 λ（只需噪声水平 ε，与荧光重建"n 统计已知"天然匹配）；外层迭代通常 10–100 量级即达可行精度；split Bregman 的内层最小二乘可用 CG+FFT 或线性化，实践中收敛稳健。
- **缺点**：内层子求解精度与罚参数 ρ 需要协调；BPDN 形式依赖可靠的 ε；相比标准 ADMM，实现路径与调参面更大。
- **收敛判据**：外层用 §2.2 投影 KKT 与 §2.3 相对对偶间隙统一验收；split Bregman 等价于 ADMM，用原始/对偶残差（见 §6）。残差类判据 ‖Ao + b − y‖ ≤ ε 用于约束式。
- **非负约束兼容方式**：投影——o ≥ 0 作为约束块（ALM 原生处理），或在分裂变量上逐次 Π≥0。
- **与本项目关系**：主力备选；其"残差加回"机制可以低成本移植进现有工作列流程做强度校正。

## 5. 变量分裂方法

- **核心思想**：引入辅助变量（z = o 或 d = Φo）把不可分离的复合目标拆成两块可交替求解的简单子问题（一个最小二乘 + 一个收缩/投影），外层用罚函数或增广拉格朗日强制两块一致；SALSA / C-SALSA 是代表实现 [10]。
- **适用场景与规模**：复合正则、去卷积类问题；规模与算子结构同上，28.6 万体素可行。
- **优点**：每步结构极简（LS 可 FFT/CG，收缩/投影闭式）；是理解与快速原型化 ADMM 的最短路径；可平滑升级到对偶提升版本。
- **缺点**：纯罚式交替（无对偶提升）时收敛性依赖罚参数且偏慢；理论保证弱于 ADMM。
- **收敛判据**：分裂一致性残差 ‖z − o‖（残差类）+ 原问题投影 KKT。
- **非负约束兼容方式**：投影（在辅助变量块上）。
- **与本项目关系**：概念上是当前"支撑选择 + 幅度校正"两阶段分解的连续化镜像，可作为最小改动的对照试验床。

## 6. 交替方向乘子法（ADMM）

- **核心思想**：对两块分裂目标的增广拉格朗日做逐块最小化 + 对偶上升，三步迭代 [11][12][13]。对本问题（非负 LASSO）：

  > x ← argmin ½‖Ax + b − y‖² + (ρ/2)‖x − z + u‖²　（解 (AᵀA + ρI)x = Aᵀ(y−b) + ρ(z−u)：CG + FFT，或线性化免内层）
  > z ← Π≥0(S_{λ/ρ}(x + u)) = max(0, x + u − λ/ρ)　（非负软阈值，闭式）
  > u ← u + x − z

- **适用场景与规模**：大规模复合凸优化的事实标准；"隐式 FFT 算子 + 28.6 万未知量 + 非负 + L1"是它的典型适用场景。
- **优点**：z 步闭式且**原生包含非负**；x 步线性系统固定（(AᵀA+ρI) 不变，可预条件/预热 CG）；两块凸问题全局收敛理论最完备；自适应 ρ 与加速方案成熟 [14]；背景 b 可作为额外自由块联合估计。
- **缺点**：ρ 与内层 CG 精度需协调；AᵀA 病态（轴向耦合）时内层 CG 慢——弹性网 μ > 0 可直接缓解（系统变为 AᵀA + (μ+ρ)I）；迭代数可到数千。
- **收敛判据**：标准原始残差 r_k = ‖x − z‖ 与对偶残差 s_k = ρ‖z⁽ᵏ⁾ − z⁽ᵏ⁻¹⁾‖，相对容差 10⁻⁴–10⁻⁶（Boyd 等 §3.3.1 停机准则 [13]）；最终仍以 §2 的 (ε_KKT, gap) 验收。
- **非负约束兼容方式**：原生（z 块投影）。
- **与本项目关系**：首选对照之一；与工作列互为 warm start——工作列的支撑初始化 z，ADMM 的解为列生成提供初值/候选列池。

## 7. 近端梯度类：ISTA、FISTA 及非负投影变体

- **核心思想**：前向（梯度）+ 后向（近端）分裂：o ← prox_{t(λ‖·‖₁ + ι≥0)}(o − t·Aᵀr)；对非负 LASSO 该近端算子退化为逐元素 max(0, v − tλ)。FISTA 加 Nesterov 动量，把 O(1/k) 加速到 O(1/k²) [15][16][17][18]。
- **适用场景与规模**：只能以黑盒方式应用 A / Aᵀ 的大规模问题——正是本项目形态；28.6 万体素毫无压力。
- **优点**：实现最小（数十行）；内存最少（3–5 个数组）；每迭代恰 1 对 A/Aᵀ（FFT）；ISTA（无动量）的当前点梯度 g = Aᵀr 每步本来就要算，KKT / 对偶监控零额外成本，但加速 FISTA 在动量点 z 计算梯度，接受迭代点 x 的证书需要额外一对 A/Aᵀ，因此按可配置间隔评估；弹性网近端仍闭式：max(0, v − tλ)/(1 + tμ)；μ > 0 强凸时可配自适应重启获得线性收敛 [19]；λ 延拓暖启动（从大 λ 到目标 λ，FPC 思路 [20]）显著减少总迭代。
- **缺点**：速率对条件数敏感——轴向耦合使 AᵀA 病态时收敛慢；λ 偏小或支撑偏大时迭代数大；需幂迭代估计步长上界 1/‖A‖²。
- **收敛判据**：§2.2 ε_KKT + §2.3 相对对偶间隙（按 certificate_stride 间隔与最终迭代点评估；加速 FISTA 每次证书评估增加一对 A/Aᵀ，ISTA 可直接复用当前点梯度）；目标值停滞作辅助。
- **非负约束兼容方式**：原生（近端投影合并为单一闭式）。
- **与本项目关系**：首选基线对照；与工作列实现共用同一证书，可直接横向比较精度/时间。

## 8. 坐标下降（glmnet 类）

- **核心思想**：固定其余坐标，对单坐标的"二次 + L1"目标求闭式最小（软阈值再作箱截断），循环或随机扫描坐标；配合 λ 从大到小的路径暖启动，即 glmnet 的事实标准做法 [21][22]。
- **适用场景与规模**：显式设计矩阵或 Gram 矩阵可预存时最有效（glmnet 面向稀疏存储的 n×p 矩阵）；本项目"隐式卷积算子 + 28.6 万坐标"下需要按坐标提取局部 PSF 列，可行但不自然。
- **优点**：单坐标更新成本仅 O(nnz(A_j))；稀疏解下多数坐标被瞬间判零；glmnet 原生支持下界为 0 的箱约束（非负直接可用）；λ 路径 + 暖启动极其成熟。
- **缺点**：与纯 FFT 的"整体前向/伴随"模式不匹配，需要列访问接口；高相关坐标（轴向邻近层）下收敛慢；理论速率一般；并行需随机化以避免写冲突。
- **收敛判据**：坐标级 KKT——全部坐标满足 §2.2 逐坐标条件即全局最优（KKT 类）；glmnet 亦报告对偶间隙。
- **非负约束兼容方式**：原生（坐标闭式解带下界 0，简单截断）。
- **与本项目关系**：不建议用于全问题；可作为支撑内 NNLS 的替代求解器（投影随机坐标下降），不过支撑小时 Lawson–Hanson 类活动集已经够快。

## 9. LARS / 同伦法

- **核心思想**：LARS 沿"最小角"方向逐变量推进，与 LASSO 的分段线性解路径等价 [23]；同伦法沿 λ 递减路径维护活动集与 KKT 条件，事件驱动地精确推进解路径 [24][25]。
- **适用场景与规模**：中小规模（约 ≤ 10⁴–10⁵）或支撑极小、列相关性温和的问题。
- **优点**：一次运行得到整条 λ 路径（选 λ 方便）；解精确（路径段内构造性满足 KKT）；算法可解释性强。
- **缺点**：列相关时变量反复进出活动集（路径振荡）、数值敏感——**轴向编码造成的跨层高相关正踩雷区**；活动集大时每步 Cholesky O(|S|³)；28.6 万体素不现实。
- **收敛判据**：KKT 类（当前 λ 处构造性满足；路径完备即最优）。
- **非负约束兼容方式**：非标准——需活动集改造（非负 LARS 无成熟通用实现）；实践上用 glmnet 下界 0 的路径替代。
- **与本项目关系**：仅用于降采样小算例（如 48×48×8 ≈ 1.8 万体素）的 ground truth 校验。

## 10. 内点法（l1_ls 类）

- **核心思想**：把 LASSO/BPDN 写成光滑的目标 + 不等式约束的 QP，用 primal-dual 内点法（log 障碍）求解；每个 Newton 步用截断牛顿 + 预条件 CG 解 KKT 方程组，矩阵-向量积只需 A/Aᵀ（结构友好）[26][27]。
- **适用场景与规模**：l1_ls 论文与官方实现报告在结构化算子下可处理 10⁵–10⁶ 量级未知数；28.6 万处于能力边缘，时间成本高。
- **优点**：高精度（对偶间隙可压到 10⁻⁸ 量级）；无需调 ρ/步长；对条件数相对稳健；有现成实现（l1_ls、CVX/TFOCS 生态）。
- **缺点**：每个内点迭代要做多次大规模线性求解，28.6 万体素下大概率十分钟到小时级；非负约束会加不等式块、KKT 系统更大；换算子结构需适配接口。
- **收敛判据**：相对对偶间隙 + 原始/对偶可行性（内点标准三元组）——对偶间隙类。
- **非负约束兼容方式**：原生可加（不等式约束直接进入障碍项）。
- **与本项目关系**：中小规模精确对照，用来标定其他方法的 gap 与支撑正确性；全规模不作主力。

## 11. 贪心类：OMP、CoSaMP、工作列/匹配追踪策略

- **核心思想**：以残差相关 Aᵀr 为"检验数"贪心选列（非负时取正相关最大者），再在支撑内做最小二乘/NNLS 校正幅度：MP [28]、OMP [29] 每步一列，CoSaMP [32] 批量选列再剪枝；"受限主问题 + 按检验数生成新列"的工作列策略与 LP 列生成同族。
- **适用场景与规模**：支撑小、信噪比可用、需要快速得到显式支撑的问题；当前实现已验证 28.6 万体素可行。
- **优点**：**原生非负**（支撑内 NNLS [3][33][34]，活动集法有限步收敛）；迭代次数 ~ 支撑大小，每步仅 1 次 Aᵀr（FFT）；支撑显式，便于后续物理约束与解释；停机检验数 max_i(Aᵀr)_i ≤ λ 正是非负 LASSO 的投影 KKT——**终检通过即拿到全局最优证书**；近亲 IHT [35] 可作批量阈值化对照。
- **缺点**：贪心本身无先验全局保证（依赖终检兜底）；高相干列（轴向邻近层）下易早选错列或支撑泄漏；对噪声与背景 b 失配敏感；λ 语义弱（停机阈值 ≈ λ，正则化强度不直接）。
- **收敛判据**：检验数 max_i(Aᵀr)_i ≤ λ + tol（投影 KKT 类）+ 相对对偶间隙；或残差/支撑饱和（残差类）。
- **非负约束兼容方式**：原生。
- **与本项目关系**：即当前方案本体；建议保留为主体，定位为"支撑定位器"，按 §15 与连续法（FISTA/ADMM）互相验证、互相暖启动。

## 12. 一阶自适应方法（Adam 等用于无约束重参数化形式）

- **核心思想**：用 o = softplus(u)（或 exp(u)、o = u² 等）消去非负约束，把目标变成无约束光滑函数（L1 用 Huber 等平滑代理或保留），跑 Adam 自适应矩估计一阶法 [36]。
- **适用场景与规模**：原型验证，或与可学习组件（网络先验、端到端系统）联合训练的场合；不作为严格逆问题求解器。
- **优点**：约 10 行代码；autodiff 生态原生；可与深度先验端到端联训。
- **缺点**：对凸问题也无收敛到最优的保证；softplus 使 o 严格大于 0（内点）→ 稀疏性差、支撑处 KKT 的等式条件无法精确满足；λ 与阈值的语义被打乱；对初始化与学习率敏感。
- **收敛判据**：无 KKT 类证书；用目标值平台/验证指标 + 与证书解的偏差做事后评估（残差/验证类）。
- **非负约束兼容方式**：重参数化（或二次罚/对数障碍的罚函数方式）。
- **与本项目关系**：不作主线；作为未来"学习先验 + 工作列"融合的接口保留。

## 13. L2 正则化（岭回归/截断 SVD 类）与 L1+L2 弹性网

- **核心思想**：岭回归/Tikhonov [4] 加 (μ/2)‖o‖²、截断 SVD [37] 截掉小奇异分量，以偏差换稳定；弹性网 [2] L1+L2 兼得稀疏与"分组效应"（相关列系数趋同）。
- **适用场景与规模**：岭回归用 CGLS/LSQR [38] 即可在大规模隐式算子上求解（迭代正则化 + 早停）；TSVD 需要显式谱分解——本项目算子因轴向混合不可整体对角化，**不可行**；弹性网与本项目完全适配。
- **优点**：弹性网 μ > 0 使 AᵀA + μI 强凸——FISTA/CG 速率提升、解对轴向相关列更稳（分组效应把跨层泄漏"摊平"而不是二选一）；一切 LASSO 求解器经 §2.1 增广恒等式直接复用；glmnet/FISTA/ADMM 均原生支持。岭回归解可作初值与条件数分析。
- **缺点**：岭/TSVD 无稀疏、无支撑（定位能力差），非负只能事后投影或转成增广 NNLS；弹性网 μ 对支撑幅度引入偏置，λ 的语义与纯 LASSO 略有不同。
- **收敛判据**：岭 → 线性方程组残差（残差类）；LSQR → 半收敛早停（L 曲线/离散偏差准则）；弹性网 → 与非负 LASSO 同型的 KKT（支撑上 g + μo = −λ）与对偶间隙。
- **非负约束兼容方式**：岭回归 → 增广 NNLS（[A; √μ I]o = [y−b; 0] 后跑活动集法 [3]）；弹性网 → 各求解器原生支持。
- **与本项目关系**：强烈建议加入小 μ 弹性网对照（μ 从 λ/10–λ/3 起步扫起），对冲轴向跨层相关的病态。

## 14. 深度展开（deep unfolding，简述）

- **核心思想**：把 ISTA/ADMM/原始-对偶迭代展开成有限层的可微网络，步长、阈值乃至算子参数可从数据学习（LISTA [39]、learned primal-dual [40]，综述见 [41]）。
- **适用场景与规模**：有训练对、追求推理速度与数据自适应正则化的场景；推理时层数 5–20，规模无碍。
- **优点**：推理快；ReLU/非负投影层天然满足 o ≥ 0；可把 FFT 卷积算子作为物理层嵌入，保持模型一致性。
- **缺点**：需要真实/仿真训练对；泛化与稳定性无保证；失去严格收敛证书（除非约束展开结构单调下降）。
- **收敛判据**：无通用证书；用验证集误差 + 各层 KKT 残差曲线评估。
- **非负约束兼容方式**：结构内置（激活/投影层）。
- **与本项目关系**：中期方向——把"工作列 + 支撑内 NNLS"流程可微化展开，学习列选择与轴向去混叠权重；先积累仿真训练数据。

## 15. 结合本项目的结论建议

**总体判断**：28.6 万体素 + 隐式 FFT 卷积算子的形态，对近端/分裂类一阶方法是"小而条件差"的问题——瓶颈是轴向耦合带来的病态与高相干，而不是规模。因此推荐组合是：**保留工作列主体（支撑定位）+ 非负 FISTA 与三分裂 ADMM 作连续松弛对照与加速路径 + 小 μ 弹性网对冲病态**。

| 优先级 | 动作 | 理由 |
|---|---|---|
| P0 | 非负 FISTA（含 μ = λ/10 弹性网变体）基线 | 成本最低、FFT 完美适配、证书按间隔评估（ISTA 复用每步梯度；加速 FISTA 每次评估一对 A/Aᵀ）、与现实现同口径可比 |
| P0 | 三分裂 ADMM / split Bregman（CG + FFT 内层，b 作自由块联合估计） | z 步非负闭式、x 步系统固定可预条件、停机准则成熟、与 FISTA 互为交叉验证；BPDN 约束式适合噪声水平已知场景 |
| P1 | λ 延拓暖启动 + 自适应重启 | FPC [20] 与重启 [19] 的工程收益，改造成本小 |
| P1 | 证书化对比协议：ε_KKT、相对 gap、支撑 F1、幅度 RMSE、时间 | 复用现有 KKT/对偶间隙代码，横向公平比较 |
| P2 | 降采样算例（如 48×48×8）用 LARS / l1_ls / glmnet(下界=0) 三方 ground truth | 一次性投入，长期防实现回归 |
| P3 | 深度展开探索 | 需训练数据，待仿真管线成熟后启动 |

**具体建议**：

1. **非负 FISTA 是最优先的备选/对照**：prox = max(0, v − tλ) 闭式、每迭代 1 对 A/Aᵀ（约几十个 96×96 FFT，毫秒级）、内存 3–5 个数组（< 20 MB）。ISTA（无动量）的梯度 g = Aᵀr 每步本来就要计算，投影 KKT 与对偶间隙可零成本监控；加速 FISTA 的梯度在动量点 z 计算，接受迭代点的证书需额外一对 A/Aᵀ，因此按可配置间隔与最终迭代点评估。证书口径与当前工作列实现完全一致——两条技术路线的解可直接按证书互相验证。
2. **split Bregman / ADMM 是第二优先**：对非负 LASSO 的三分裂形式，z 步 = max(0, · − λ/ρ) 同时完成软阈值与投影，x 步 (AᵀA + ρI) 固定不变，可用 CG + FFT（或按弹性网加 μ 变成 AᵀA + (μ+ρ)I，更好预条件）；能把背景 b 作为额外块联合估计是它对当前流程的独有便利。停机用原始/对偶残差，终点仍以 (ε_KKT, gap) 验收。
3. **弹性网 μ > 0 必做**：轴向增益编码使相邻 z 层系统列高度相关，AᵀA 病态是贪心误选与一阶法收敛慢的共同根源；μ ≈ λ/10–λ/3 的弹性网在 FISTA（prox 分母 1+tμ）、ADMM（Hessian 加 μ+ρ）中都是一两行改动，且所有 LASSO 证书直接沿用（KKT 改为 g + μo = −λ 于支撑）。
4. **工作列主体保留，角色重定位**：它是"非负 + 稀疏"的原生活动集方法，支撑显式、终检 KKT 通过即全局证书——这是它的独特价值。建议定位为**支撑定位器**：支撑喂给 FISTA/ADMM 做主动集初始化；FISTA/ADMM 的连续解 top-K 反哺候选列池。两者互补而非替代。
5. **验证矩阵**：全规模用 (ε_KKT ≤ 10⁻⁵·max(λ, ‖g‖∞), gap ≤ 10⁻⁴) 双证书验收；降采样小算例上与 LARS/l1_ls/glmnet 的精确解对比支撑 F1 与幅度误差，确认无系统性偏差后再回到全规模。
6. **不推荐**：Adam/重参数化作主线（无证书、稀疏性差）；全量 TSVD（隐式算子谱不可得）；全问题坐标下降（列访问与 FFT 模式不匹配）；l1_ls 全规模（时间不经济，仅作小算例对照）。
