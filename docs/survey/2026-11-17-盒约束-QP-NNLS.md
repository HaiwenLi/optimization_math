- **日期**：2026-11-17
- **状态**：调研（T4，P1）

## 1. 问题形式与记号

盒约束二次规划（box-constrained QP）：

\[
\min_{x\in\mathbb{R}^n}\quad \tfrac12 x^T Q x + c^T x,\qquad \text{s.t. } l_i \le x_i \le u_i.
\]

- `Q ∈ ℝ^{n×n}` 对称**半正定**（`Q ⪰ 0`），`c ∈ ℝ^n`，`l,u ∈ (ℝ∪{±∞})^n`。
- **特例**：非负最小二乘 NNLS 为 `l=0, u=+∞` 且 `Q=AᵀA, c=−Aᵀy`（即 `min_{x≥0} ½‖Ax−y‖²`）；单纯形约束为 `l=0, Σx=1`（需另加等式/投影）；带符号 box 为 `l=−∞,u=+∞` 退化为无约束。
- 与 T1/T2 的差异：**无 L1 稀疏项，改由 box 约束决定可行域**；近端算子就是框投影 `proj_box`（逐坐标 clip），闭式。

## 2. 最优性证书

### 2.1 KKT 条件

目标 `f(x)=½xᵀQx+cᵀx`，梯度 `g=Qx+c`。box 约束的一阶最优性（投影 KKT）：

\[
\begin{cases}
g_i = 0, & l_i < x_i < u_i,\\
g_i \ge 0, & x_i = l_i \ \text{(下界紧，梯度指向内部)}\\
g_i \le 0, & x_i = u_i \ \text{(上界紧)}.
\end{cases}
\]

归一化违反度（逐坐标，对每个坐标取"违反量"）：

\[
\varepsilon_{\rm KKT}=\frac{\max_i \operatorname{viol}_i}{\max(1,\|g\|_\infty)},\quad
\operatorname{viol}_i=\begin{cases}
|g_i|, & x_i\in(l_i,u_i),\\
\max(0,-g_i), & x_i=l_i,\\
\max(0,g_i), & x_i=u_i.
\end{cases}
\]

### 2.2 强对偶与相对间隙

box-QP 是强对偶（凸、Slater 成立当约束内部非空）。拉格朗日：

\[
L(x,\mu_l,\mu_u)=\tfrac12 x^TQx+c^Tx-\mu_l^T(x-l)+\mu_u^T(x-u),\quad \mu_l,\mu_u\ge0.
\]

驻点条件 `Qx+c-\mu_l+\mu_u=0`，由它取 `μ_l = max(0,g)`（下界方向）、`μ_u = max(0,-g)`（上界方向），`g=Qx+c`。

**实现口径（二次下界 gap，代码 `certificates_qp.py`）**：无限端点没有相应的有限约束，不能用上述乘子并把无限端点替换为 0；那会产生高于最优值的伪下界。令 `m=max(0,λ_min(Q))`，由半正定性：

\[
f(x+d)\ge f(x)+g^Td+\tfrac12 m\|d\|^2,\qquad l-x\le d\le u-x.
\]

当 `m>0`，逐坐标取 `d=clip(−g/m,l−x,u−x)` 最小化右侧；当 `m=0`，沿梯度符号选取盒端点（零梯度项贡献为 0）。该最小值作为 `Certificate.dual` 的下界，`relative_gap=(primal−dual)/max(1,|primal|,|dual|)`。

若奇异 `Q` 的线性下界沿无界方向无下界，则返回 `dual=−∞, relative_gap=+∞`，不冒充收敛；这可能保守，即实际问题有界但该下界不足以认证。当前密集实现每次证书计算需要特征值分解，大规模适用性未验证。

## 3. 算法谱

| 算法 | 核心迭代 | 优点 | 缺点 | 与本仓库关系 |
|---|---|---|---|---|
| 投影梯度（PG）/ FISTA | `x←proj_box(x−t g)` | 闭式投影、实现最小 | 一阶收敛（Q 病态则慢） | **推荐主推**，复用 `fista_signed.py` 骨架换 prox=框投影 |
| 活动集法（NNLS 经典） | 分块求解 + 支撑增删 | 有限步收敛、高精度 | 实现中等 | 对照（后续扩展） |
| 内点法 | 对数障碍 + 牛顿 | 高精度 | 大规模慢 | 小算例对照 |

**选型**：主推 **投影梯度**（box 近端 = clip，无 L1 项故 FISTA 退化为普通 PG，或保留动量加速）。证书为 §2 的 box-KKT + 强对偶 gap。

## 4. 自建案例（真值已知）

1. **对角 Q 解析锚点**：`Q=diag(d_i)`，`c` 任意，解 `x_i = clip(−c_i/d_i, l_i, u_i)`（逐坐标独立，闭式）。
2. **NNLS 特例**：`Q=AᵀA, c=−Aᵀy` 小矩阵，与非负 FISTA（已实现）交叉验证。
3. **随机对称半正定 Q**：`Q=BᵀB`，真值 `x_true` 落在 box 内/边界混合，验证 box 打包恢复。
4. **病态 Q**：条件数大，测投影梯度的收敛速度（迭代数）。
