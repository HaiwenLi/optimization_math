## 1. 问题形式与记号

带符号（无 box 约束）的 LASSO / 弹性网：

\[
\min_{x\in\mathbb{R}^n}\quad \frac12\|Ax-y\|_2^2+\lambda\|x\|_1+\frac{\mu}{2}\|x\|_2^2,\qquad \lambda>0,\ \mu\ge 0.
\]

与已实现的**非负** LASSO 的唯一区别是去掉 `x ≥ 0`：解不再被投影到正象限，稀疏项 `λ‖x‖₁` 的阈值从「投影软阈值」退化为「普通软阈值」`S_t(v)=sign(v)·max(0,|v|−t)`。

**记号**：`A ∈ ℝ^{m×n}` 为线性算子（本仓库走 `LinearOperator`，仅 `shape/matvec/rmatvec`），`y ∈ ℝ^m` 观测，`r = Ax − y` 残差，`g = Aᵀr` 梯度。

## 2. 最优性证书

### 2.1 KKT 条件

目标 `f(x) = ½‖Ax−y‖² + λ‖x‖₁ + (μ/2)‖x‖²` 的次梯度条件：

\[
0 \in A^T(Ax-y)+\mu x+\lambda\,\partial\|x\|_1.
\]

即逐坐标（`g = Aᵀr + μx`）：

\[
\begin{cases}
g_i = -\lambda\cdot\operatorname{sign}(x_i), & x_i\neq 0,\\
|g_i| \le \lambda, & x_i = 0.
\end{cases}
\]

**归一化违反度**（与非负版同口径，只是丢掉 `x>0`/`x=0` 的非负分支，改用 `x≠0`/`x=0`）：

\[
\varepsilon_{\rm KKT}
=\frac{\max\left(\max_{x_i\neq 0}|g_i+\lambda\operatorname{sign}(x_i)|,\ \max_{x_i=0}(|g_i|-\lambda)_+\right)}
{\max(\lambda,\ \|g\|_\infty)}.
\]

### 2.2 对偶下界与相对对偶间隙

沿用与现有 `certificates.py` 相同的推导口径（残差参数化）。引入中间变量 `z = Ax`，约束 `z = Ax` 配拉格朗日乘子 `ν`，对 z、x 分别取极小得 LASSO 对偶：

\[
\max_{\nu:\ \|A^T\nu\|_\infty\le\lambda}\ -\tfrac12\|\nu\|_2^2 - \nu^T y.
\]

（l1 共轭为指示函数 `𝟙{‖Aᵀν‖∞≤λ}`，二次项共轭给 `−½‖ν‖²`；符号约定与 Boyd 形式差一个 `ν→−ν`，无实质区别。）

给定迭代解 `x` 与残差 `r = Ax − y`。为使对偶目标值非平凡（下界），取对偶可行点 `ν = θ(y − Ax) = −θ r`，约束 `‖Aᵀν‖∞ = θ‖Aᵀr‖∞ ≤ λ` 给出缩放

\[
\theta=\min\!\Big(1,\ \frac{\lambda}{\|A^Tr\|_\infty}\Big).
\]

（上式为 `μ=0` 形式；含 `μ>0` 时梯度 `q = Aᵀr + μx`，缩放须取 `θ = min(1, λ/‖q‖∞)`，见 §2.3。）

代入对偶目标得下界。注意本实现与 `certificates.py` 采用相同的残差参数化口径（`ν = −θ r`，线性项 `−νᵀy` 与背景项 `θ·(b−y)ᵀr` 在 `b=0` 时一致），无背景 `b` 时为：

\[
d(\theta)=-\tfrac12\theta^2\|r\|_2^2 - \theta\,y^T r.
\]

（代码以 `-0.5*theta^2*(‖r‖² + mu‖x‖²) + theta*(b−y)ᵀr` 实现，与现有 `compute_certificate` 的 `dual` 公式完全同构。）

相对间隙：

\[
\mathrm{gap}=\frac{p-d}{\max(1,|p|,|d|)},\qquad p=\tfrac12\|r\|^2+\lambda\|x\|_1+\tfrac\mu2\|x\|^2.
\]

> 与非负版的区别：非负版因 `x≥0` 使对偶可行域多一个符号限制（θ 只按 `q=Aᵀr+μx` 的**负分量**取 min）；带符号版无 box，θ 直接按全量 `‖q‖∞`（`q=Aᵀr+μx`，μ=0 时即 `‖Aᵀr‖∞`）取 min(1, λ/‖q‖∞)。二者代码骨架相同，仅 θ 的取值域与 KKT 分支（`x≠0`/`x=0` vs `x>0`/`x=0`）不同。[1][2]

### 2.3 弹性网（μ > 0）的处理

μ 项 `(μ/2)‖x‖²` 光滑可微，不影响次梯度结构，只把梯度换为 `q = Aᵀr + μx`。KKT 沿用 §2.1 的 `q_i = −λ sign(x_i)` / `|q_i| ≤ λ`；对偶下界的二次项系数按共轭调整为 `−½θ²(‖r‖² + μ‖x‖²)`，且 **θ 须按 `‖q‖∞`（而非 `‖Aᵀr‖∞`）取**：`θ = min(1, λ/‖q‖∞)`。这一取值是保障下界性质的必要条件——间隙可写为

\[
p-d = \tfrac12(1-\theta)^2(\|r\|^2+\mu\|x\|_2^2)+\lambda\|x\|_1+\theta\,x^Tq \ge 0,
\]

其非负性依赖 `θ|q_i| ≤ λ`，仅当 θ 按 `q = Aᵀr+μx` 而非 `Aᵀr` 定标时才成立。故**带符号弹网与非负弹网共享同一套 KKT/对偶代码骨架，仅去掉非负分支**。

## 3. 算法谱

| 算法 | 核心迭代 | 优点 | 缺点 | 与本仓库关系 |
|---|---|---|---|---|
| ISTA / FISTA（近端梯度） | `x^k = S_{tλ}(x−tAᵀr)`（软阈值） | 实现最小、内存 O(n)、每步 1 对 A/Aᵀ | 一阶收敛（μ=0 时次线性）；μ>0 强凸可线性 | **直接复用** `fista.py` 的近端骨架，换 prox 为软阈值、去掉投影 |
| 坐标下降（glmnet 类） | 逐坐标闭式软阈值 | 常迭代即高精度、稀疏 | 稠密 AᵀA 列访问代价高 | 小/中规模基准对照 |
| ADMM（三分裂） | x 步 CG、z 步软阈值 | 强凸移位、可预条件 | 迭代多、调 ρ | **复用** `admm.py`，z 步换为 `S_{λ/ρ}(x+u)`（去 `max(0,·)`） |
| 坐标/内点（l1_ls 类） | 截断牛顿 CG | 高精度对偶间隙 | 大规模慢 | 小算例对照 |

**选型**：主推 **带符号 FISTA**（prox = 软阈值，复用现有 `_run_stage` 骨架），ADMM 做交叉验证。证书为 §2 的软阈值 KKT + 相对对偶间隙。

## 4. 自建案例

1. **解析锚点**：标量 `A=[[1]]`，`x* = S_λ(y) = sign(y)max(0,|y|−λ)`（可手算）。
2. **对角算子**：`A=diag(a)`，逐坐标 `x*_i = sign(y_i)max(0, |a_i y_i|−λ)/a_i²`。
3. **高斯设计矩阵稀疏回归**：`n=100, m=40, k=10` 非零真值（含负权重），验证软阈值解能恢复**负号支持**（这是与非负版的关键差异——非负版会把这些负权重截成 0）。
4. **弹网交叉**：μ>0 下与解析 `S` 解一致（系数 `(1+μ)` 分母）。

## 6. 基准结果（自建案例，真值已知）

问题：高斯设计 `A ∈ R^{80×200}`，真值 `k=15` 稀疏且**含负权重**，`y = A x_true + 0.05·noise`，`λ = 0.1·‖Aᵀy‖∞`；5 个噪声种子取均值 ± 标准差。

| solver | iters | ε_KKT | rel.L2 | support F1 | amp.RMSE |
|---|---|---|---|---|---|
| fista-signed（带符号） | 185 ± 36 | 9.7e-6 | **0.25 ± 0.015** | **0.82 ± 0.10** | **0.23 ± 0.037** |
| fista-nonneg（非负对照） | 255 ± 21 | 3.3e-6 | 0.83 ± 0.10 | 0.23 ± 0.08 | 0.68 ± 0.09 |

**自动判定结论**（基准自带断言，均通过）：
- 两者都收敛、证书达标（ε_KKT ≤ 1e-5、rel.gap ≤ 1e-5）。
- **带符号版支撑 F1（0.82）显著高于非负版（0.23）**，相对误差低 3 倍——因为非负版把负权重坐标全部截为零。这是带符号版存在的量化依据。
- 迭代代价略优于非负版（185 vs 255）。
