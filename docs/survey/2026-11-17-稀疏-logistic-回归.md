# 稀疏 logistic 回归（penalized logistic）调研

- **日期**：2026-11-17
- **状态**：调研（T2，P0）
- **归属**：总路线图 `docs/survey/2026-11-17-算法调研扩展总路线图.md` 的 T2

## 1. 问题形式与记号

二分类稀疏 logistic 回归（`ℓ₁`-penalized logistic）：

\[
\min_{w\in\mathbb{R}^p}\quad
\frac1N\sum_{i=1}^N \log\!\big(1+e^{-y_i w^T x_i}\big) + \lambda\|w\|_1,
\qquad \lambda>0.
\]

- `X ∈ R^{N×p}` 设计矩阵，`y_i ∈ {−1,+1}` 标签，`w` 待求权重（**无 box 约束**）。
- 令 `a_i = y_i x_i ∈ R^p`；损失（除以 N 规范化）`ℓ_i(w) = log(1+e^{−a_iᵀw})`。
- **与 T1 的差异**：光滑项从 `½‖Ax−y‖²`（二次）换成 logistic 损失（无二次结构），稀疏项同为 `λ‖w‖₁`。证书的 KKT 骨架与 T1 **完全相同**，只有梯度 `g` 与对偶目标 `φ*(·)` 换了。

## 2. 最优性证书

### 2.1 梯度与 KKT

损失梯度（记 `σ_i = σ(−y_i wᵀx_i) = 1/(1+e^{y_i wᵀx_i})`，即样本 i 的错分类概率）：

\[
g = \nabla f(w) = \frac1N\sum_{i=1}^N (-a_i)\,\sigma_i
 = -\frac1N\sum_i y_i x_i\,\sigma_i.
\]

次梯度条件 `0 ∈ ∇f(w) + λ∂‖w‖₁` 逐坐标：

\[
\begin{cases}
g_j = -\lambda\,\operatorname{sign}(w_j), & w_j\neq 0,\\
|g_j| \le \lambda, & w_j = 0.
\end{cases}
\]

归一化违反度与 T1 同型（`g_j = ∇f(w)_j`，无 box 分支）：

\[
\varepsilon_{\rm KKT}
=\frac{\max\left(\max_{w_j\neq0}|g_j+\lambda\operatorname{sign}(w_j)|,\ \max_{w_j=0}(|g_j|-\lambda)_+\right)}
{\max(\lambda,\ \|g\|_\infty)}.
\]

### 2.2 Fenchel 对偶与相对间隙

logistic 损失 `φ(t)=log(1+e^{−t})` 的 Fenchel 共轭（定义域 `s∈[−1,0]`）：

\[
\phi^*(s) = -s\log(-s) + (1+s)\log(1+s).
\]

原始问题（`A_{i:}=a_iᵀ=y_i x_iᵀ`）的对偶为

\[
\max_{\nu}\ -\frac1N\sum_{i}\phi^*(-N\nu_i),\qquad \text{s.t. }
\ \|A^T\nu\|_\infty = \Big\|\sum_i \nu_i\, y_i x_i\Big\|_\infty \le \lambda .
\]

给定迭代解 `w`，取对偶可行点 `ν_i = θ·σ_i`（`σ_i` 为错分类概率）。可行条件：

- `‖Aᵀν‖∞ = θN‖g‖∞ ≤ λ` ⇒ `θ ≤ λ/(N‖g‖∞)`；
- `φ*` 定义域 `−Nν_i ∈ [−1,0]` ⇒ `θ ≤ 1/(N σ_max)`，`σ_max = max_i σ_i`。

故

\[
\theta=\min\!\Big(\frac1N,\ \frac{\lambda}{N\|g\|_\infty},\ \frac{1}{N\,\sigma_{\max}}\Big),\qquad
d(\theta)=-\frac1N\sum_i\phi^*(-N\theta\sigma_i).
\]

相对间隙：

\[
\mathrm{gap}=\frac{P(w)-d(\theta)}{\max(1,|P(w)|,|d(\theta)|)}.
\]

**紧性**：当 `w→w*` 时 `θ→1/N`，故 `−Nν_i→−σ_i`，`d→P(w*)`，`gap→0`。不能把起始缩放设为 `1`：均值损失的最优对偶点是 `ν_i=σ_i/N`，在高 λ 的零解处尤其需要保持这个归一化。

## 3. 算法谱

| 算法 | 核心迭代 | 优点 | 缺点 | 与本仓库关系 |
|---|---|---|---|---|
| 近端梯度（ISTA/FISTA） | 软阈值近端，梯度为 logistic 梯度 | 实现小、每步 1 次 X/Xᵀ 扫描 | Lipschitz 常数 `‖X‖₂²/(4N)`（`σ_max·‖X‖²/4` 归一化到均值），需估计 | **推荐主推**，复用 `fista_signed.py` 骨架（换梯度与 prox） |
| 坐标下降（glmnet logistic） | 逐坐标二阶近似软阈值 | 高精度、稀疏 | 稠密列访问 | 小规模对照 |
| 随机/近端（SAGA/SVRG） | 方差缩减近端 | 大数据可扩展 | 实现复杂 | 后续扩展 |
| ADMM | 光滑项线性化/分裂 | 无调 L 依赖 | logistic 无闭式 x 步 | 需线性化，非首选 |

**选型**：主推 **logistic-FISTA**（软阈值近端 `S_{tλ}`，梯度 = logistic 梯度，Lipschitz 默认 `‖X‖₂²/(4N)`，其中 `1/4` 为 logistic 二阶导上界、`/N` 来自均值归一化损失）。证书为 §2 的 KKT + Fenchel 对偶间隙。

零设计矩阵时该上界为 0；实现采用正的回退步长常数，以便从非零 warm start 通过软阈值收敛到零解，而不是除以 0。样本数与特征数必须为正。

## 4. 自建案例

1. **解析锚点**：`N=1, p=1`，单样本 `(x=1, y=+1)`。`w* = 0` 当 `λ ≥ max |∇f(0)| = 1/N·|x|·σ(0) = 1/2`；否则 `w*` 由一维方程 `g(w)+λ sign(w)=0` 数值解出，用二分法锁定（独立于求解器）。
2. **可分/混合数据**：`p=20, N=200`，真值 `w_true` 中 `k=5` 非零，`y_i = sign(x_iᵀw_true)` 掺少量标签翻转噪声，验证稀疏恢复与分类精度。
3. **独立 ground truth（测试内自建，无外部依赖）**：单样本解析解 `w* = −log(λ/(1−λ))`（λ<1/2）与高低 λ 下的零解，作为证书紧性与求解器精度的独立锚点；多特征场景以「证书达标 + 真值支撑指标」自证，不引入 sklearn 等外部求解器。

## 7. 基准结果（自建案例，真值已知）

合成二分类：`X ∈ R^{300×40}`，真值 `w_true` 中 `k=8` 非零（含负权重），标签按逻辑概率抽样（含翻转噪声）；3 个种子。

| λ | iters | ε_KKT | rel.gap | rel.L2 | support F1 |
|---|---|---|---|---|---|
| 0.05 | 33 ± 2 | 9.0e-6 | 6.7e-7 | 0.588 | **0.80** |
| 0.02 | 67 ± 3 | 9.5e-6 | 6.1e-7 | 0.367 | 0.53 |
| 0.01 | 106 ± 7 | 9.4e-6 | 4.4e-7 | 0.337 | 0.44 |

**自动判定结论**：
- FISTA-logistic 全程收敛、证书达标（ε_KKT ≤ 1e-5、rel.gap ≤ 1e-5），对偶下界紧（gap ~ 1e-7）。
- **λ 与支撑 F1 非单调**：λ=0.05 附近 F1 最高（~0.8）；λ 继续减小，recall→1 但 precision 骤降（解误纳小权重、不再稀疏），F1 反降。这一非单调性只能靠「真值已知 + 支撑指标」量化发现，无法凭直觉判断。
- 迭代数随 λ 减小单调增加。
